# Мэндлэх ёс

Монголчуудын мэндлэх ёс заншлын тухай интерактив слайд дэк.
**Хэл ярианы соёл · Семинар III**

## Тухай

31 слайдаас бүрдсэн, хөтчид шууд ажилладаг танилцуулга. Гадны сан (framework,
library) ашиглаагүй — цэвэр HTML, CSS, JavaScript. Офлайн, `file://` дээр ч
нээгдэнэ.

Агуулга:

1. **Мэндчилгээний мөн чанар** — утга, гурван давхар
2. **Уламжлалт ёс** — төрөл, дараалал, гэрийн ёс
3. **Золголт ба хадаг** — цагаан сарын ёслол
4. **Орчин үе** — "та"/"чи", биеийн хэл, цахим мэндчилгээ
5. **Харьцуулалт ба дүгнэлт** — дэлхийн ёс, зөв ба буруу

## Ажиллуулах

Тусгай бүтээх алхам шаардлагагүй:

```bash
python3 -m http.server 8000
# эсвэл index.html-ийг хөтчид шууд нээнэ
```

## Удирдлага

| Товч | Үйлдэл |
| --- | --- |
| `↓` `↑` `Space` `PageUp/Dn` | Дараагийн / өмнөх слайд |
| `←` `→` | Слайд эргүүлэх (3D бөгж дээр — эргүүлэх) |
| `Home` `End` | Эхний / сүүлийн слайд |
| `1`–`9` | Тухайн слайд руу үсрэх |
| `F` | Бүтэн дэлгэц |

Хулганы дугуй, мобайл дээр хурууны шудрах хөдөлгөөн мөн ажиллана.

## Бүтэц

## Гэрэл зураг

Бүх гэрэл зураг **Wikimedia Commons**-оос авсан, чөлөөт лицензтэй (CC BY,
CC BY-SA, CC0, нийтийн эзэмшил). Зохиогч, лиценз, эх хуудасны жагсаалтыг
[`img/credits.json`](img/credits.json) файлаас үзнэ үү. Мөн дэкийн "Баг"
слайдын доод хэсэгт эх сурвалж бүрийн холбоос харагдана.
